# Online_food_ordering_system
Project Overview:-

The Online Food Ordering System is a web-based application developed using PHP, MySQL, HTML, CSS, JavaScript, and XAMPP. The system allows customers to browse food items, place orders, and manage their accounts online. Administrators can manage food items, categories, customers, and orders through an admin dashboard.

Objectives:-
Provide an easy platform for customers to order food online.
Reduce manual order processing.
Manage food items and customer orders efficiently.
Generate a user-friendly ordering experience.


Technologies Used:-
Frontend: HTML, CSS, JavaScript, Bootstrap
Backend: PHP
Database: MySQL
Server: Apache (XAMPP)
Development Tool: Visual Studio Code


Features:-
Customer Module
User Registration and Login
Browse Food Menu
Search Food Items
Add Items to Cart
Place Orders
View Order History
Update Profile
Admin Module
Admin Login
Manage Food Categories
Add, Update, Delete Food Items
View Customer Details
Manage Orders
Update Order Status
Dashboard Reports

System Requirements:-
Windows/Linux Operating System
XAMPP Server
PHP 7.4 or Above
MySQL Database
Web Browser (Chrome, Edge, Firefox)
